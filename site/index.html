local-llmup

A hardware-aware command line for local LLMs

Discover the best model for your machine, pull it, serve it, chat with it, and migrate memory when you switch. One workflow. Local-first.

Quickstart

  1. npm install -g local-llmup
  2. npx local-llmup
  3. local-llmup up qwen3:30b-a3b
  4. local-llmup chat -m qwen3:30b-a3b

Core Commands

  • recommend find top fits for your hardware
  • up <model> install + start server
  • switch <model> set active served model
  • migrate move memory between models
  • doctor run diagnostics for local stack

Why It Feels Fast

  • Hardware-aware ranking from a curated model catalog
  • Clear install and serve lifecycle through Ollama
  • State + memory migration built for daily model switching
  • CLI output designed for both humans and scripts
